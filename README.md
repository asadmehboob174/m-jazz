# M.JAZE — website

Website for **M.JAZE (PVT) LTD**, Lahore — solar systems, lithium batteries, UPS, CCTV, IT, projectors and event rentals.

Built with Next.js 15 (App Router), Tailwind CSS 4, Motion, Lenis and Matter.js.

## Run locally

```bash
npm install
npm run dev     # http://localhost:3000
```

## Where things live

- `lib/data.ts` — all content: products, packages, projects, reviews, FAQs, company details.
  Everything marked **SAMPLE** is demo data and must be replaced before launch.
- `app/` — pages (home, services, shop, product, project)
- `components/` — UI sections
- `app/globals.css` — theme tokens, light/dark themes and the 7 accent colour themes
